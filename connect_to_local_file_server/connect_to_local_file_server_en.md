# Connect to the UMS file server

From the Ubuntu desktop, click on 'Files'.

![Click on 'Files'](1_click_on_files.png)

In 'Files', click on 'Other locations' to see the other locations.

![Click on 'Other locations'](2_click_on_other_locations.png)

In 'Files', click on the location 'UMS NAS'.

![Click on 'UMS NAS'](3_click_on_ums_nas.png)

In 'Files', click on the UMS NAS location called 'TMP'.

![Click on 'TMP'](4_click_on_tmp.png)

In the pop-up dialog, click on 'Connect'.

![Click on 'Connect'](5_click_on_connect.png)

Now you are connected to the UMS file server!

![Done!](6_done.png)
