# umstutorials

A home for UMS tutorials that fit worse someplace else.

## The problem is solves

The Uppsala Makerspace has an app with tutorials. The code for this section of the app
[has the same name, but in singular](https://github.com/uppsala-makerspace/umstutorial).
Using that repository for content that does not fit elsewhere, is a bad idea:
that repo should focus on being the tutorial part of the UMS app.

This repository is the place to give tutorials (i.e. the **content**) that have no
natural place to go a home.
